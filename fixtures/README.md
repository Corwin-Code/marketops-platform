# Fixtures

Test data for MarketOps Russia.

## Policy

Every fixture in this directory is **synthetic**. It is written by hand or
generated, and it describes no real person, order, product, or account.

Real Marketplace API responses, real reports, and production log excerpts must
not be placed here, even when they appear harmless. The repository is public
during pre-production, so anything committed here is world-readable.

Data derived from a real source through an approved redaction process is also
excluded while the repository is public. It may be reconsidered only after the
repository becomes private and the redaction process itself has been approved.

## Buyer personal data

Buyer names, phone numbers, addresses, and any other personal data never enter
this repository, including in test environments.

## Naming

Fixture identifiers are obviously synthetic. They never reuse a real store,
warehouse, or account identifier, so a fixture can never be mistaken for
production data during an incident.

## Current contents

The foundation carries no business behaviour, so no data fixture exists yet.
This policy is recorded before the first fixture is added, not after.
